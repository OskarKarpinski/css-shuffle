# CSS Shuffle Examples

Ready-to-run examples demonstrating `css-shuffle` in various setups:

| Example | Description | Tech Stack |
|---------|-------------|------------|
| [`astro-static`](./astro-static) | Pre-rendered static Astro website (SSG) | Astro 5 |
| [`astro-ssr`](./astro-ssr) | On-demand server-side rendered website (SSR) | Astro 5 + `@astrojs/node` |
| [`vite`](./vite) | Modern frontend application with Vite plugin | Vite 6 |
| [`node-cli`](./node-cli) | Programmatic post-build directory obfuscation | Node.js |
